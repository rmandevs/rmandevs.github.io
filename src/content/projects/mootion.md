Mootion is a layout for [Herdr](https://herdr.dev) that makes a room full of terminals feel like a workspace of pages.

- **Spaces as pages.** A sidebar page tree where each space unfolds into its tabs, with emoji or icons
- **Terminals as pages.** Each pane gets a header with its agent, folder, branch and status
- **Agents as teammates.** Each agent gets a face, a colour and a name, and messages you when it is done or needs you
- **Files, Changes and Notes** as pages too, with light and dark themes

It only runs on your machine, and the README lists every command it uses.
